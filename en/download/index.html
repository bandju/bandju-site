VPS requirements

Server requirements

Installing Bandju Panel requires a VPS/VDS with root SSH access, public IPv4, and Docker support. We recommend a VPS/VDS with Ubuntu 22.04/24.04 LTS.

Scenario Recommended parameters
Minimum for simple use 1 vCPU, 2 GB RAM, 15 GB SSD
Recommended for stable operation 2 vCPU, 2-4 GB RAM, 20 GB SSD

Important

  • KVM/VDS virtualization is preferred.
  • Docker must run without restrictions and be able to manage network rules.
  • Ports 80 and 443 must be available for domains and certificates.
  • The provider must not block incoming TCP/UDP ports used by VPN protocols.

Not recommended

  • VPS plans with 1 GB RAM.
  • NAT VPS without its own public IPv4.
  • Container VPS plans with Docker, firewall, TUN/WireGuard, or iptables restrictions.
  • Overloaded cheap VPS hosts where the server responds slowly even when plan specs look sufficient.
Version 1.8.0

What is new in BandjuPanel 1.8.0

A short summary of the latest release. The full version history is available in the changelog.

  • Added a new Backups section for saving services, settings, and accesses to a local file.
  • A clean VPS can be fully restored, while a configured VPS can safely import accesses without overwriting its current settings.
  • Before restoring, panel shows a detailed plan and checks compatibility, missing services, ports, domain, and DNS.
  • Added VPS-to-VPS migration: IP and domain settings are adapted, while connections that need a new config or rebinding are marked separately.
