Version 1.8.0

What is new in BandjuPanel 1.8.0

A short summary of the latest release. The full version history is available in the changelog.

  • Added a new Backups section for saving services, settings, and accesses to a local file.
  • A clean VPS can be fully restored, while a configured VPS can safely import accesses without overwriting its current settings.
  • Before restoring, panel shows a detailed plan and checks compatibility, missing services, ports, domain, and DNS.
  • Added VPS-to-VPS migration: IP and domain settings are adapted, while connections that need a new config or rebinding are marked separately.
